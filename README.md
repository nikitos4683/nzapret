**nzapret** — автономный и легковесный модуль для Android-устройств с root-доступом. Модуль работает **на базе [zapret2](https://github.com/bol-van/zapret2)**, что является его отличительным преимуществом и современным подходом к обходу блокировок. Под капотом используется локальный движок `nfqws2` и правила `iptables`/`ip6tables` для перехвата DPI.

Бинарники, пейлоады и списки маршрутизации (lists) взяты из оригинального апстрима, но весь код обвязки написан с нуля под Android — с красивым интерфейсом и без лишнего мусора в системе.

## ✨ Ключевые возможности

- **Встроенный WebUI для KernelSU:** Детально проработанный и красивый графический интерфейс прямо в вашем менеджере модулей.
- **Мощный CLI:** Полный контроль над поведением модуля через терминал.
- **Легковесная конфигурация "из коробки":** Встроенные правила рассчитаны на мобильные сети и смартфоны и не требуют дополнительной настройки для базового сценария.
- **Умный роутинг:** Незаметный перехват трафика в цепочках `OUTPUT` и `FORWARD` для IPv4 и IPv6.
- **Режим IPv4-only:** При необходимости модуль можно перевести в отдельный режим только для IPv4-сетей без задействования IPv6-цепочек.
- **Управление Private DNS:** Модуль умеет инициализировать системный `Private DNS` значением `xbox-dns.ru` и позволяет переключать провайдера из WebUI и CLI. Это необходимо для корректного обхода блокировок ИИ-сервисов (ChatGPT, Claude, Gemini и др.), которые помимо DPI могут блокироваться на уровне DNS.
- **Персональный `list-user`:** Собственный список доменов пользователя с редактированием из WebUI и CLI.
- **Локальная автономность:** Служба не выходит в сеть при загрузке устройства и использует только локальные данные.
- **Горячее обновление списков:** Скачивание и обновление доменных листов маршрутизации вызовом одной команды.
- **Совместимость с VPN:** Модуль рассчитан на совместную работу с большинством VPN-клиентов. *(Если ваш VPN использует экзотические сетевые интерфейсы и возникают конфликты — смело открывайте Issue, мы постараемся это исправить!)*

По умолчанию режим стека определяется автоматически при первом запуске: если на устройстве виден рабочий IPv6, сохраняется `auto`, иначе модуль сам переключается в `ipv4-only`. Ручной переход обратно в `auto` разрешён только при доступном IPv6 на текущей сети; если IPv6 недоступен, WebUI и CLI не дадут сохранить `auto`. После ручной смены через WebUI или CLI выбор пользователя больше не перезаписывается автоматически.

`Private DNS` также инициализируется один раз при первом запуске: если Android Private DNS уже находится в режиме provider hostname и там задан валидный хост, модуль сохраняет его без изменений. Во всех остальных режимах (`auto` / `off` / пусто) nzapret выставляет дефолтный provider hostname `xbox-dns.ru`. После ручной смены через WebUI или CLI выбранный DNS-режим больше не перезаписывается автоматически.

### 🚧 Ограничения и известные проблемы
> **Telegram:** Поддержка Telegram работает через встроенный helper `tgwsproxy`. Его жизненный цикл объединён с основным сервисом `nzapret`: команды `start / stop / restart` управляют сразу и `nfqws2`, и `tgwsproxy`. Отдельно доступна служебная команда `nzapret tg link` для получения tg:// ссылки.
>
> **Instagram:** Обход блокировки Instagram работает только в режиме **Auto** (IPv6/IPv4). В режиме `ipv4-only` Instagram не разблокируется. Для работы Auto ваша мобильная сеть (оператор) или Wi-Fi сеть должна поддерживать IPv6.
>
> **Баг WebUI в KernelSU ~~(и KernelSU-Next)~~:** Из-за бага менеджера ~~ksun (issue [#1180](https://github.com/KernelSU-Next/KernelSU-Next/issues/1180)),~~ процесс модуля `nfqws2`, запущенный *вручную* кнопкой Start из WebUI, может "умирать" (закрываться системой) после смахивания KernelSU из недавних приложений. **(В KernelSU-Next баг повержен! Наш фикс успешно смержен в апстрим 🚀 Но на обычном KernelSU проблема всё ещё остаётся).** Если вы сидите на оригинальном KSU (или старой версии KSU-Next) и столкнулись с этим, лучше всего запускать модуль встроенной кнопкой **Action** в самом менеджере модулей (она автоматически определяет статус и безопасно включает/выключает службу), либо через терминал командой `nzapret start`. При автостарте вместе с системой nzapret работает стабильно.

## 🏗 Архитектура и структура

Модуль состоит из нескольких компонентов, которые работают в единой слаженной связке:

### ⚙️ Ядро: `service.sh` и CLI

- **`service.sh`** — главный системный скрипт модуля. Стартует вместе с системой, загружает встроенную конфигурацию обхода, пересобирает правила фаервола под текущую конфигурацию и запускает процессы `nfqws2` и `tgwsproxy`.
- **`system/bin/nzapret`** — основной мозг управления (CLI). Предоставляет команды для запуска, остановки, перезапуска рантайма и обновления листов (hostlists). Общие команды жизненного цикла управляют сразу всем модулем, а `nzapret tg link` выдаёт текущую tg:// ссылку. Также именно CLI генерирует телеметрию в JSON-формате для работы WebUI.
- **`uninstall.sh` / `action.sh`** — утилиты для корректной очистки правил `iptables`, остановки запущенных процессов и быстрой работы кнопки Вкл/Выкл в интерфейсе.

### 🎨 WebUI (Интерфейс)

Модуль содержит собственный Web-интерфейс (`webroot/`), который интегрируется в KernelSU.
- Отображает подробный статус устройства (версия, PID, количество правил и доменов).
- Позволяет управлять модулем (Start / Stop / Restart).
- **Встроенный визуальный редактор** для управления персональным списком доменов (`list-user`).
- Содержит вкладки с системными логами службы и логами диагностики в реальном времени.
- Имеет встроенный режим диагностики проблем, помогающий выявить причины неполадок на конкретном устройстве.
- Вся связь между UI и модулем работает через вызовы к CLI (`nzapret status --json`).

### 📂 Данные и Конфигурация

- **`profiles/`** — служебные конфигурационные файлы `nfqws2`.
- **`lists/`** — текстовые списки доменов для выборочного роутинга трафика.
  Встроенные листы обновляются отдельно, а персональный `list-user` хранится как пользовательский runtime-файл и не должен теряться при обновлении модуля.
- **`payloads/`** — бинарные фейковые пакеты (TLS/QUIC) для обмана оборудования провайдеров.
- **`lua/`** — Lua-библиотеки `nfqws2`, подключаемые конфигурацией через `--lua-init`.

## 🚀 Быстрый старт

### 1. Установка
1. Скачайте готовый `ZIP-архив` со страницы релизов (Releases) или соберите модуль из исходников самостоятельно.
2. Прошейте стандартным способом через **Magisk** или **KernelSU**.
3. Перезагрузите устройство.
4. Откройте вкладку модулей в KernelSU для доступа к **WebUI**. *(Если вы используете Magisk, установите приложение [KsuWebUI](https://github.com/KOWX712/KsuWebUIStandalone) для работы с интерфейсом, либо управляйте модулем по старинке через терминал).*

### 2. Использование из терминала

Для управления через CLI потребуется терминал (например, Termux) и root-права (команда `su`).
*Примечание: Если команда `nzapret` не найдена в системном пути, используйте полный путь: `/data/adb/modules/nzapret/system/bin/nzapret`*

**Жизненный цикл:**
```sh
nzapret start    # Инициализировать правила и запустить nfqws2
nzapret stop     # Остановить процесс и очистить цепочки фаервола
nzapret restart  # Полный перезапуск с применением новых настроек
```

**Мониторинг:**
```sh
nzapret status         # Посмотреть текущее состояние и статус службы
nzapret status --json  # Вывод статуса машинной обработкой (для WebUI)
nzapret log            # Посмотреть последние записи системного лога
nzapret diagnose       # Собрать и показать диагностическую информацию
```

**tgwsproxy:**
```sh
nzapret tg link           # Показать текущую tg:// ссылку
```

**Списки, сеть и DNS:**
```sh
nzapret update         # Скачать и обновить списки обхода (hostlists)
nzapret network status      # Посмотреть текущий режим стека (auto / IPv4-only)
nzapret network set ipv4-only # Зафиксировать режим только для IPv4-сетей
nzapret network set auto      # Вернуть Auto, если на текущей сети доступен IPv6
nzapret dns status          # Посмотреть текущее состояние Android Private DNS
nzapret dns set default     # Применить дефолтный provider hostname: xbox-dns.ru
nzapret dns set auto        # Вернуть системный автоматический Private DNS
nzapret dns set off         # Полностью отключить системный Private DNS
nzapret dns set hostname dns.example.com # Установить свой provider hostname
nzapret list-user status    # Статус персонального списка и домены
nzapret list-user show      # Показать текущее содержимое
nzapret list-user add example.com youtube.com # Добавить домены в персональный список
nzapret list-user remove example.com          # Удалить домен из персонального списка
nzapret list-user replace example.com github.com # Перезаписать список
nzapret list-user clear     # Полностью очистить список
```

## 🛠 Сборка модуля

Если вы хотите собрать модуль самостоятельно, у вас в системе (Linux/WSL) должны быть установлены базовые утилиты: `bash`, `zip`, `sed`, `mktemp`.

Процесс сборки запускается всего одной командой:
```sh
bash build.sh
```
На выходе в корневой директории появится готовый к прошивке архив `nzapret-vX.Y.Z.zip`. Собирать можно прямо на устройстве (например, в Termux) или на ПК.
